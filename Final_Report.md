# SOC Week 2 Report

## Introduction
This project demonstrates the Security Operations Center (SOC) workflow including alert classification, alert triage, incident response, and evidence preservation.

## Alert Classification
Security alerts were categorized based on severity using CVSS scoring and MITRE ATT&CK mapping.

## Alert Triage
Alerts were investigated to determine priority and whether escalation was required.

## Incident Response
A simulated ransomware incident was documented including indicators of compromise and containment steps.

## Evidence Preservation
Digital evidence such as memory dumps and network logs were recorded with hash values.

## SOC Workflow
The complete SOC workflow includes detection, investigation, containment, recovery, and lessons learned.

## Conclusion
This exercise demonstrates how SOC analysts handle security alerts and respond to incidents in a structured manner.
