# Incident Ticket

## Title
[Critical] Ransomware Detected on Server-X

## Description
A ransomware executable named crypto_locker.exe was detected on Server-X.
The malware attempted to encrypt files and communicate with external IP 192.168.1.50.

## Indicators of Compromise

| Indicator Type | Value |
|---------------|------|
| File Name | crypto_locker.exe |
| IP Address | 192.168.1.50 |
| File Hash | a1b2c3d4e5f6 |

## Action Taken
The infected endpoint was isolated from the network to prevent further spread.
SOC analysts initiated investigation and malware removal procedures.
